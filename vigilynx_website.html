WHAT VIGILYNX DETECTS

Three core detection modules working in real-time using background subtraction and computer vision.

📱
PHONE DETECTION

Identifies phones held during exams using shape analysis. Fires after 5 consistent frames with 20-second suppression to avoid spam.

● ACTIVE
👀
HEAD TURN DETECTION

Tracks face position using Haar Cascade. Detects sustained lateral head movement over a 2-second window — filters out natural twitches.

● ACTIVE
👥
CROWD DETECTION

Detects 10+ people gathering with 8+ closely spaced individuals using contour clustering. Monitors corridors and entrances.

● ACTIVE
HOW IT WORKS
DETECTION PIPELINE

01

02
PREPROCESS
