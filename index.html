WHAT VIGILYNX DETECTS

Three core detection modules working in real-time using background subtraction and computer vision.

📱
PHONE DETECTION

Identifies mobile phones held by students during exams using shape analysis, aspect ratio filtering, and edge density checks. Fires an alert after 5 consistent frames with 20-second suppression to avoid spam.

● ACTIVE
👀
HEAD TURN DETECTION

Tracks face position using Haar Cascade. Detects sustained lateral head movement over a 2-second window — differentiating genuine cheating glances from natural head movement during exams.

● ACTIVE
👥
CROWD DETECTION

Detects gatherings of 10 or more people with 8+ closely spaced individuals using contour clustering. Useful for monitoring corridors, entrances, and outdoor spaces for unauthorised assemblies.

● ACTIVE
HOW IT WORKS
DETECTION PIPELINE

From raw camera feed to logged alert in under one second.

01
CAPTURE

Webcam feed captured via OpenCV DirectShow at 640×480. Buffer flushed every frame to eliminate lag.

02
PREPROCESS

Frame resized, converted to grayscale, Gaussian blurred. Background subtractor builds a motion mask.

03
DETECT

Contours extracted from motion mask. Each contour checked by Phone, Head Turn, and Crowd detectors simultaneously.

04
ALERT

On confirmation, alert logged to MongoDB (or in-memory), sound played via winsound, flash overlay triggered.

05
DASHBOARD

Flask REST API serves live stats and alert log. This website polls every 1.5–3s for real-time updates.
